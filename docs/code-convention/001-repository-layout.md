# Convention 001: Repository Layout

Planned; not scaffolded yet.

```
Dockerfile                     builds the diplex-core engine image (Python, LibreOffice, unoserver, fonts)
LICENSE                        MIT
diplex-core/                   Python engine (uv)
  src/diplex_core/
    definition/                Pydantic models: the API contract (source of the OpenAPI spec)
    engine/
      docx_to_pdf/             unoserver pool and supervision
      pages/                   PDF -> WebP page images
      checks/                  input checks: size, pages, macros, zip bombs
    api/                       FastAPI route: render
  tests/
diplex-sdk/                    @diplex/sdk (TypeScript)
  procedures/                  createDocument, getDocument, updateDocument, deleteDocument, exportDocument
  storage/                     S3 key layout, writes, presigned URLs, folder delete
  client/
    types.gen.ts               generated from diplex-core's OpenAPI; never edited by hand
    http.ts
  index.ts
diplex-store/                  @diplex/store (TypeScript)
  tables/
    documents.ts               Drizzle table + SCHEMA_VERSION
  migrations/                  SQL generated by drizzle-kit, for consumers on any ORM
diplex-playground/             sample website that consumes Diplex through @diplex/sdk (never published)
docs/                          see docs/README.md
scripts/
  conventions/                 the convention checker (convention 010)
.claude/settings.json          Claude Code project settings: the Stop hook that runs the checker
samples/                       real test documents (git-ignored, never committed)
```

- **The Python folder is `diplex-core`, but the importable package is `diplex_core`,** because Python names cannot contain hyphens.
- **The hosted gateway is not in this layout yet;** it may be a managed service ([ADR 006](../adr/006-hosted-and-self-hosted.md)).
- **`samples/` is git-ignored** and must never be committed.
